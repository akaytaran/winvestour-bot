# Contributing

Thank you for your interest in winvestour-bot.

## Code contributions are not accepted

This repository is a published copy of the owner's private repository. Releases flow one way — from the private repository to this one — so **pull requests and code contributions are not accepted** here, and pull requests are turned off for this repository.

The software is MIT-licensed: you are free to fork it and change your own copy as you like (see `LICENSE`).

## What is open

- **Bug reports** — open an issue with the **Bug report** template.
- **Installation questions** — open an issue with the **Installation help** template, or ask in **Discussions → Q&A**.
- **Security reports** — never in a public issue. Use **Security → Report a vulnerability** (private vulnerability reporting); see `SECURITY.md`.

## Before you post

Never paste an API key, password, TOTP secret, stop key, `.env` value or database connection string into an issue, a discussion or a screenshot. Nobody here will ever ask you for one. If you pasted one by mistake, delete it and rotate the value immediately.
