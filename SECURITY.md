# Security policy

## Reporting a vulnerability

Report security problems **only** through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do **not** open a public issue or discussion for a security problem.

Please include what is affected, how to reproduce it and what an attacker could do. Do not include real API keys, passwords, TOTP secrets or `.env` values — describe them instead.

## Supported versions

| Version | Supported |
|---|---|
| 1.x | yes |
| older | no |

There is no bug bounty. This software is provided under the MIT licence, "as is", without warranty (see `LICENSE`).
